ADI_STORE_V1 — prototype
==========================
This is a browser-based prototype containing:
- Customer catalog
- Item images, descriptions and prices
- UPI QR checkout
- Order submission with UTR/reference
- Admin login
- Add/edit/delete catalog items
- Order status management

IMPORTANT:
This prototype stores data in browser localStorage and contains demo/client-side admin credentials. It is NOT secure for production.
For a real Android app, move authentication, catalog, orders, payment verification and any delivery data to a secure backend/database.
Do not collect or expose game-account passwords through an insecure frontend, and make sure any marketplace activity complies with the game's Terms of Service.

Open index.html in a browser to test it.
